# AI/ML-Based Traffic Congestion Prediction Using Lightweighted Urban Digital Twin

## Overview

Traffic congestion is a major challenge in urban areas, leading to delays, increased fuel consumption, and inefficient transportation.

This project aims to predict future traffic congestion using Artificial Intelligence (AI) and Machine Learning (ML). It considers traffic data along with factors such as weather conditions, time, and event information to estimate future traffic conditions.

The project also proposes a virtual traffic environment to test and compare possible traffic management strategies before implementing them on real roads. The results can be presented through a Smart City Dashboard to support data-driven decision-making by traffic authorities.

## Objectives

- Predict future traffic congestion using machine learning.
- Analyse the relationship between traffic conditions, weather, time, and events.
- Explore suitable traffic datasets and ML models.
- Simulate and compare traffic management scenarios.
- Identify potential interventions to reduce congestion.
- Provide understandable explanations for model predictions.
- Support traffic authorities through data visualization and decision-support tools.

## Key Features

### 1. Traffic Congestion Prediction
Uses historical and available traffic-related data to estimate future traffic conditions.

### 2. Data Analysis
Analyses traffic patterns and relevant factors such as vehicle speed, traffic volume, weather, and time.

### 3. Virtual Traffic Scenario Evaluation
Proposed functionality to compare possible interventions, such as:
- Adjusting traffic signal timings.
- Diverting vehicles to alternative roads.
- Evaluating the impact of road closures.

### 4. Explainable AI
Explores ways to explain which input features influence traffic congestion predictions.

### 5. Smart City Dashboard
Planned dashboard functionality includes:
- Predicted congestion levels.
- Traffic data visualizations.
- Comparison of traffic scenarios.
- Potential traffic management recommendations.
- Explanations of prediction results.
